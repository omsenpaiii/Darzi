# Selected design system

The latest hero direction starts from immersive-hero-concept.png (superseding hero-concept.png). The remaining implementation starts from work-concept.png, craft-concept.png, contact-concept.png, admin-concept.png and admin-mobile-concept.png. The user authorised autonomous implementation; concept selection follows that scope.

- Surfaces: charcoal #161817, paper ivory #F5F2EA, wine #552629. The public hero image carries its own light/shadows, with no colour wash. Hairlines #CDC8BD; muted light text #B8B5AE; ivory text #F5F2EA. Wine text on ivory; pale wine #B97780 for readable accents on charcoal.
- Typography: Bodoni Moda for editorial display (normal and italic), Source Sans 3 for readable interface controls/body. IBM Plex Mono for IDs and small operational metadata. Bodoni desktop hero approximately 100–116px at 1536px, 52–64px at mobile widths. Native controls explicitly sized 15–17px; inputs 16px.
- Layout: 72px desktop gutters, 1280px maximum content where useful, 24px mobile gutters. Angular unframed compositions, open editorial bands, asymmetric 2:1 work imagery; no generic rounded marketing cards. Admin can use bounded tables/boards as its task requires.
- Header: homepage navigation overlays the scene, without a background or separator; items sit centrally between the wordmark and outline consultation action. DARZI wordmark, Services, Weddings, Our work, Our craft, Request a consultation. Mobile accessible disclosure/menu. Wordmark is live typesetting until an approved existing mark is supplied; do not invent an EST year.
- Hero copy: Every detail. / Made around / you. Supporting text: A personal commission. A considered silhouette. / Tailoring that starts with you. CTAs: Request a consultation, Explore our work. Location: Melbourne, Australia. Latest direction uses scroll-driven construction and no play/pause/replay controls. Short construction chapters replace the introduction during scrolling; the top navigation keeps the consultation action available.
- Homepage order: hero → material statement and selected work → pattern-to-presence chapters → service links/fabric teaser → studio/contact. Real client testimonials are withheld until provided. Shared service/gallery/contact templates extend the same approved component families.
- Motion: native page scroll, a full-viewport hero pinned for approximately 3.6 viewport-heights, cross-dissolving consistent original suit assembly keyframes on a capped-resolution canvas; scoped GSAP opacity/transform reveals and one responsive craft-story sticky media stage. No scroll hijacking. Mobile stacks chapters; reduced motion shows ordinary static content. Essential information is visible without animation.
- Icons: Lucide outline icons 1.5px stroke, arrows18–22px; navigation uses only meaningful controls. No decorative status indicators on public pages.
- Art: original AI concept imagery is labelled Design studies where it might otherwise imply actual client commissions. Private admin photos remain private. The assembly uses original keyframes; a continuous HeyGen film is pending a suitable creation route/API key. It must preserve the same subject and geometry and remain scroll driven.
- Intentional deviations: the old concept's small EST.MELBOURNE replaced with MELBOURNE on ordinary pages and omitted on the immersive homepage (unverified establishment claims omitted). Hero static state has no nonfunctional film playback control. No fabricated testimonials. Separate factual policies remain approval drafts.

Verification will compare concepts and browser screenshots across copy, palette, layout, typography, media treatment and mobile behaviour.
